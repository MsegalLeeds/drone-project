# Documentation

GitHub is the project's live engineering record. The formal Word report can contain the polished final narrative; GitHub should preserve the working process, evidence and decisions.

## Documents

- [requirements.md](requirements.md) — measurable system requirements and constraints.
- [architecture.md](architecture.md) — high-level hardware/software architecture.
- [decisions/](decisions/) — engineering decision records.

## Documentation rule

For an important design choice, record:

**problem → research/calculation → options → decision → justification → verification → result**

Link calculations, experiments, issues and pull requests where possible.
